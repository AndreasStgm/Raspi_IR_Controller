# Raspberry Pi IR Controller

All-in-one setup for a Raspberry Pi to control an AC over IR.

## Prerequisites

Since this is an embedded project, there are soft- and hardware requirements to be met to use this project.

### Hardware

You need a Raspberry Pi and an IR LED module connected to it via the GPIO.

### Software

You need a clean Raspbian (or other Debian-based) installation running on a Raspberry Pi.
